A tiny deterministic program that writes one unsent micro-confession — a To: line and the single line that stayed in drafts — to entry.txt for make.fun's "Unsent: The Micro-Confession Sprint" bounty.

The program uses only the Python standard library, takes no input, and writes the exact same bytes on every run. The confession is kept in `main.py` as a single constant, so the output is fully reproducible.

## Run it

```sh
python3 main.py
```
